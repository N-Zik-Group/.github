# 🤝 Contributing to .github

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 



## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/N-Zik-Group/.github.git

## ✅ Verify your changes

Edit `profile/README.md` for changes to the public organization profile. Preserve the contributor grid markers maintained by GitHub Actions and check project links.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
